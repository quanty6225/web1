Introducing TickTick 3.8.0 with more powerful “Duration” function.

A new version of TickTick has been released for iOS & Andriod. We made some key improvements in this new update. “Time Duration” function is now supported to work across more than one day. Users can set both start time and end time to a task with custom time duration.  Tap into the “Duration” settings and select from Normal/Advanced mode. Normal mode: Set time duration within one day. Advanced mode: Custom time duration for tasks that last two or more days. Tasks have durations will display differently in Calendar View. A brand new city theme for Seoul is available for premium users in TickTick 3.8.0. iOS premium users can also change the application icon that displays on the homescreen. Enjoy. TickTick Team
