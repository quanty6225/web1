    Monday.com Importer

    Last modified on Tue, 6 Oct 2026
    Quick answer: To import from Monday.com, copy your Personal API Token from Monday.com's Admin › API tab. Then a site admin opens Settings › Import in Teamwork.com, clicks Import in the Monday.com panel, pastes the token and chooses what to import. Only v2 API tokens are supported.

    Note: The importer displays a maximum of 1000 projects. If your account contains more than 1000 projects, please get in touch with us.


    How do I import projects from Monday.com into Teamwork.com?

    Step 1: Locate your Monday.com API token

    Your Monday.com personal API token is required to use the importer.

    1. Log in to Monday.com.
    2. Go to the Admin area.
    3. Switch to the API tab.
    4. Click Copy on the Personal API Token field's right. Click Regenerate if you want to issue a new token.
      ⚠️ Only v2 API tokens are supported with this import tool.



    Step 2: Initiate the import in Teamwork.com

    🔑 Site admins (in the owner company) can access a site's import settings.

    1. Click your profile icon in Teamwork.com's main navigation menu.
    2. Select Settings.



    3. Switch to the Import tab.
    4. Scroll to the Monday.com panel.




       
    5. Click Import.
    6. Enter your copied Monday.com API token.



    7. Click Next.
    8. Choose which items to import:
      1. People: All people
      2. Projects: All projects or specific projects
      3. Project items: All of the following items within the selected projects (ex. tasks, files and comments.)



    9. Click Import.
    You can wait for the import to finish or close the window. You will receive a confirmation email as soon as the import is complete.


    What task data is imported?

    • Tasks and subtasks will be imported
      • The tasks will be created in a Teamwork.com tasklist which will inherit the Monday group name
      • Active and completed tasks
      • User assigned to task based on the owner field of the Monday item
      • Due dates
      • Task descriptions
      • Comments - Monday item updates will be mapped as sequential comments in Teamwork.com
      • Files linked to task and comments

    What should I know about imported data?

    • Tasks imported are not mapped to workflow stages on Teamwork.com projects.
    • Monday item custom fields are not mapped to, or created in Teamwork.com
    • Monday item dependencies are not carried over with the exception of subtasks
    • Monday item updates will be in sequential order based on date of creation. The updates will not be nested as the are in Monday.
    • Inline images on the task description as well as comments will appear with a placeholder on Teamwork.com but the file will be added to the task and appear on the project file page
    • Imported users are not automatically sent an email invitation to your Teamwork.com site. You can manually invite imported users by clicking the envelope icon (invite option) beside a user in your Teamwork.com site's People area.
    • Monday project activity does not populate in the Teamwork.com Home area's activity stream or in individual projects' Dashboard activity stream. Only changes made to the content after import is shown in these areas.

    Frequently asked questions

    Which Monday.com API tokens work?

    Only v2 API tokens are supported with this import tool.

    Is there a limit on how many projects I can import?

    The importer displays a maximum of 1000 projects. If you have more, get in touch with the support team.

    Who can import from Monday.com?

    Site admins in the owner company can access a site's import settings.
