    ClickUp Importer

    Last modified on Wed, 23 Oct 2024
    ✔ Available on Free Forever, Starter, Deliver, Grow, and Scale subscriptions 1

    What
    		Import your projects from ClickUp to Teamwork.com.
    Why
    • Get up and running quickly and efficiently in Teamwork.com.
    • Set yourself up for a smooth onboarding process for your team.
    Who
    • Site admins (in the owner company) can run data imports.
    When
    You have large amounts of data you want to bring into Teamwork.com so that you can continue with ongoing work.

    Before you start

    • ClickUp lists must be in a folder for them to be imported to Teamwork.com (lists not in a folder aren't imported). So, before you start an import, make sure any lists you need imported are in a folder. Hack: create a "No Folder" in ClickUp to add any folder-less lists to. 
    • When you import (or re-import), make sure all ClickUp items being imported do not have names already in use in your Teamwork.com site.

    Import from ClickUp

    Step 1: Generate your ClickUp personal API token

    1. Log in to your ClickUp account.
    2. Click your profile image, then select Apps.
    3. Scroll to API Token, then click Generate.
    4. Click Copy beside the generated token.

    Step 2: Start the import in Teamwork.com

    1. Click your profile image, then select Settings.
    2. Select Import from the settings navigation menu.
    3. Scroll to the ClickUp section.
    4. Click Import.



    5. Paste your copied ClickUp API token into the token field.
    6. Click Next.


       
    7. Select the workspace you want to import.
    8. Click Next.
       

       
    9. Choose how to import your ClickUp users:
      1. All users
      2. No users If you select this option, you can manually add users to Teamwork.com later.
    10. Use the checkboxes to select which of the workspace's spaces and folders to import.


       
    11. Click Import.

    The import begins — it might take some time, but don't worry, you'll receive an email once the import is completed.

    Once the import is finished, you can start working with your imported projects and users. Change is...change. Check below for best practices on how to get your team on board with Teamwork.com.


    Reimport

    In order to reimport projects, please delete the existing project in Teamwork.com first before running the import again.
    ⚠️ Do not archive the project — the import will not update an archived project and restore it to active status.

    Data mapping

    ClickUp and Teamwork.com use different work hierarchy structures. The importer maps certain ClickUp item types into corresponding Teamwork.com items to ensure data is brought over effectively.
     
    ⚠️ Exceptions
    Folder statuses, custom fields, and attachments from ClickUp are not carried over to Teamwork.com.

    Best practices

    • Prepare: Organize your ClickUp data before starting the import. Any lists you want to carry over to Teamwork.com must exist within ClickUp folders. Lists that are not in folders will be skipped during import.
    • Pick a transfer day: Technically, you can reimport (see above) but it can get tricky depending on where you’ve added new content. So our recommendation? Tell your team when the import is happening and have a clean cut off date for the data transfer.
    • Manage change: Switching tools isn’t just about moving data over, help your team by following some good change management basics: explain why the change is happening, tell people what they have to look forward to (what made you switch!), provide clear timelines and expectations and help equip your team with training.
