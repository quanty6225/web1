    User Permissions and Access

    Last modified on Tue, 6 Oct 2026
     Quick answer: Teamwork.com has three user types. Standard users can have full access, up to site administrator. Client users get similar project permissions but no admin rights, on up to 5 active projects. Collaborators have reduced permissions. Client users and collaborators don't count towards your subscription cost.

    What user types are there in Teamwork.com?

    • Standard users can have full access to your site with permissions right up to site administrator level if you wish.
    • Client users can be granted similar project-level permissions to standard users but cannot have any administrator privileges on your site. They do not count towards the cost of your subscription. Clients can be on a maximum of 5 active projects associated with the external company in which they are a member. Client users are available on Deliver, Grow, and Scale plans.
    • Collaborators do not count towards your subscription cost but they have reduced permissions compared to standard users and client users.

    Who can view rates and financial information?

    💰
    Financial data visibility: Site-wide billable and cost rates are visible to site owners and owner company site administrators. Project-level hourly rates, budgets, and profitability are controlled through separate project permissions.

    Permission area
    		What it controls
    Site-wide rates
    		Site-wide billable and cost rates for users. These are visible to site owners and owner company site administrators.
    View Hourly Rates
    		Ability to view hourly rates used on a project. The View Time Log permission is also required.
    Edit Hourly Rates
    		Ability to edit hourly rates used on a project. Collaborators cannot be granted view or edit hourly rate permissions.
    View Project Budget and Manage Project Budget
    		Access to project budget information. The View Time Log permission is required before budget permissions can be granted.
    View Project Budget Profitability
    		Access to project profitability information. This can expose cost-based financial information and may allow users to infer cost rates in some cases.

    1. The ability for project administrators to add new users to the account is a site-level setting. This setting is enabled by default and can only be managed by owner company site admins. Project admins from external companies can only add users from their own company, or users they already share projects in common with, to the project.

    2. For collaborators, the Add permission for messages and files only allows them edit access to items they create.
    ﻿
    3. Collaborators with permission to View Forms can only view the published form, not the form editor.

    4. Users in the owner company, as well as users with the profile permission to manage people and companies, always have permission to view people on projects.

    5. The View Time Log permission needs to be turned on in order to grant a standard user or client user permission to View Project Budget. Collaborators cannot be granted any budget-related permissions.

    6. The View Project Budget and Manage Project Budget permissions need to be turned on in order to grant a standard user or client user permission to View Project Budget Profitability. Granting all three permissions also allows the user to create and manage fixed fee budgets.
    ⚠️
    Enabling this permission may (in some cases) allow the user to calculate other users' cost rates. For example, if only one user has logged eight hours and the budget's reported cost is $800, it may be possible to conclude that user's cost rate is $100/hour. Only enable this permission for users who should have access to sensitive financial information.
    7. The View Time Log permission needs to be turned on in order to grant a standard user or client user permission to View Hourly Rates. Collaborators cannot be granted permission to View or Edit Hourly Rates.

    Which project areas can each user type access?

    Access to the different tabs of a project are dependent on:
    • The project feature being turned on for the project.
    • The user having the specific project permission to view the feature. Access to some features cannot be granted to certain user types.
    📝
    If a client user collaborator needs access to a restricted permissions, they will need to be upgraded to a standard user.

    Frequently asked questions

    Who can see site-wide billable and cost rates?

    Site owners and owner company site administrators.

    Can collaborators view hourly rates?

    No. Collaborators can't be granted view or edit hourly rate permissions.

    What do users need before budget permissions can be granted?

    The View Time Log permission.
