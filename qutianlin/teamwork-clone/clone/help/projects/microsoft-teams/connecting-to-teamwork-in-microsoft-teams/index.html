    Microsoft Teams Integration

    Last modified on Fri, 8 May 2026
    ✔  Available on Deliver, Grow, and Scale subscriptions 1

    What
    View and interact with your Teamwork.com projects in Microsoft Teams using tabs. Create new Teamwork.com tasks, messages and comments.
    Why
    • Collaborate on projects directly from Microsoft Teams.
    • Share what you are working on with your team to provide updates as tasks progress.
    • Create Teamwork.com items from Microsoft Teams messages and requests, turning conversations into trackable work.
    Who
    • Site admins, project admins, and standard users (all in the owner company) can set up the integration.
    • Each person who wants to use Microsoft Teams integration needs to set it up to use it.
    When
    If your team is using Microsoft Teams and Teamwork.com.

    Before you start

    • There are two Teamwork.com ↔ Microsoft Teams integrations: the view/create integration (this is what this page is about) and the automations integration. These integrations are completely independent of one another and their connections/disconnections are not linked.
    • To find and install the Teamwork.com app in Microsoft Teams, Teamwork.com must first be approved by a Microsoft Teams administrator.
    • You'll give Teamwork.com access to data when setting up the Microsoft Teams integration. Learn about Teamwork.com's privacy policy.
    • The Microsoft Teams integration can only be integrated with channels. Chats are not supported.

    Install the Teamwork.com app

    ﻿Install the Teamwork.com app in Microsoft Teams to be able to share Teamwork.com items within Microsoft Teams and add Teamwork.com project tabs.

    1. Open the Microsoft Teams app.
    2. Select Apps from the left navigation menu.
    3.  Search “Teamwork.com” within the Apps area.
    4. Click the Teamwork.com card.
    5. Click the Add button to add the integration. This only adds the integration for you - it won't affect your team members.

       
    The Teamwork.com app is installed in Microsoft Teams. You can post Teamwork.com items and add Teamwork.com project tabs. You'll just have to sign in to Teamwork.com as you interact with the app.

    Another option...

    Add Teamwork.com directly to a team.
    1. Click the arrow to the Add button's right.
    2.  Select Add to a team. 
    3. Search for and select a team or channel name. 
    4. Click Set up. 
    You'll then be prompted to link a Teamwork.com project as a tab. Find out more on this below. 

    Add a project tab in Microsoft Teams

    Add a Teamwork.com project tab to Microsoft Teams to view and interact with the project from Microsoft Teams. 

    1. Open Microsoft Teams. 
    2. Click Teams and select a team. 
    3. Click the + icon to add a new tab. 
    4. Search for and select Teamwork.com from your available apps. 
    5. Select the Teamwork.com tab.
    6. Click Connect with Teamwork.com. 
    7. Log in to your Teamwork.com account. You can add multiple Teamwork.com tabs in Microsoft Teams and even use Multiple Teamwork.com accounts if needed. 
    8. Follow the prompts to allow third-party access to your Teamwork.com data. 
    9. Choose a project and view: 
      1. Project: Use the dropdown to search for and choose a project. 
      2. View: Select a project view to display in the tab — Dashboard, List, or Gantt.
    10. Click Save. 

    A Teamwork.com project tab is added to the team and you can now interact with the project and its tasks.

    📝 Everyone with access to the team will see the tab, but they'll need to log in with Teamwork.com to see the tab's contents and interact with it.

    Create a Teamwork.com task

    Create a Teamwork.com task from Microsoft Teams.  

    1. Open a Microsoft Teams Posts tab. 
    2. Click New conversation. 
    3. Click the ... (ellipsis) and select the Teamwork.com app.
    4. Click the + icon. 
    5. Select Add a Teamwork.com task. 
    6. Choose a project to create the task in. 
    7. Click Next. 
    8. Select a task list. 
    9. Add a task title. Want to get detailed? Add task attributes with shortcodes (there's a section in this below). 
    10. Add a task description. 
    11. Set a due date.
    12. Click Next.
    13. Review the task and ensure task details are correct. If you need to make an update, click Edit. 
    14. Select Send. This creates the task in your chosen Teamwork.com project. 

    Comment on a task

    Add comments to Teamwork.com tasks from Microsoft Teams.  

    Comment from a task post

    1. Open a Teams Posts tab.
    2. Find an individual post about a task and click Add a comment. 
    3. Enter your comment and click Save comment. 

    Another option...

    Reply to a comment directly using the Reply option on a Teamwork.com post. Type your comment in the text field and click Save reply. Your comment is added to the task in Teamwork.com.

    💡 @mentions are supported in comments.

    Use shortcodes

    Use shortcodes in the task title field when you're creating Teamwork.com tasks via Microsoft Teams to set additional task properties.
     
    Shortcode
    		Notes
    Start and end dates
    Format: [start date][due date]

    Examples:
    [today][tomorrow]
    [2023/01/05][2023/01/15]
    Add after the task title.

    You must match the date format to the format set in your Teamwork.com localization settings.

    Use one date reference to set only a due date.
    Assignee
    Format: @name

    Example:     @jane
    Add after the task title.

    If auto assign is off and an assignee isn't added here, task list defaults in Teamwork.com is applied.
    Tags
    Format: #tagname

    Examples:
    #Development |  #[To do]
    Add after the task title.

    Multiple tags can be referenced on a task.
    Priority
    Format: !

    Examples:
    ! |  !! |  !!!
    Add before the task title.

    ! = low
    !! = medium
    !!! = high
    Estimated time
    Format: [time]

    Examples:
     [1h] |  [10m] |  [1h 25m] |  [1:30]
    Add after the task title.

    Set estimated time in hours and minutes.

    Search and post

    Search for and post Teamwork.com tasks, projects, people, and spaces in Microsoft Teams. 

    ⚠️ Search options can only be used in the legacy classic version of Microsoft Teams. This is due to Microsoft deprecating app search support in the latest Microsoft Teams version.

    Via a new conversation

    1. Click New conversation from your team's Posts tab. 
    2. Click the ... (ellipsis)
    3. Search for and select the Teamwork.com app. 
    4. Select the relevant tab depending on what you're looking for: 
      1. Tasks
      2. Projects
      3. People
      4. Spaces 
    5. Search for and select the appropriate item. 
    6. Click the send icon in the bottom right. 
    The item is posted in your team channel along with relevant details (project, task list etc). These details are clickable and open the corresponding item in Teamwork.com in a new browser tab.

    Via the search bar

    1. Search for and select @Teamwork.com from the team's search bar. 
    2. Click the Teamwork.com app from the results. This enables searching within Teamwork.com. 
    3. Click the search field and select the item type to search for: tasks, projects, people, or spaces. Added bonus: you can search for and within individual spaces.
       
       
       
    4. Search for and select the appropriate item.
    5. Click the copy icon to the right. The item is copied to your clipboard and you can use it to post the item within Microsoft Teams.

    Search for and comment on any task

    1. Search for and select @Teamwork.com from the search bar. 
    2. Click + Comment on a task.
    3. Select a project, then click Next.
    4. Search for a task based on task name, then click Search. 
    5. Click Select on one of the matching results. 
    6. Enter your comment, then click Save comment. 

    Create a Teamwork.com message

    Add a Teamwork.com project message from Microsoft Teams. 

    1. Search for and select @Teamwork.com from the search bar. 
    2. Click + Post Project Message. 
    3. Search for a project. 
    4. Enter a subject line (i.e message title). 
    5. Enter your message and click Send. 


    Disconnect and uninstall Teamwork.com app 

    Disconnect

    Disconnecting the Teamwork.com app signs you out of the Teamwork.com account you're currently logged in with. 

    1. Open Microsoft Teams.
    2. Click the ... (ellipsis) from the left navigation.
    3. Locate and click the Teamwork.com app.
    4. Select the Configuration tab. 
    5. Click Sign out. 

     
    The Teamwork.com app is disconnected and you are logged out of your Teamwork.com account within Microsoft Teams.



    Uninstall

    Uninstalling the Teamwork.com app means you will no longer be able to use Teamwork.com app functionality (search for and post Teamwork.com items or add project tabs) within Microsoft Teams.

    1. Open Microsoft Teams.
    2. Click the ... (ellipsis) from the left navigation.
    3. Search for the Teamwork.com app. 
    4. Right click the app. 
    5. Select Uninstall and confirm your choice. 


    The Teamwork.com app is uninstalled from your Microsoft Teams instance. This won’t affect anyone else in your account. 

    Best Practices

    • Tell your team: Microsoft Teams and Teamwork.com are very team-oriented. So, share the integration, and get everyone on board.
