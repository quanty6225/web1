    Microsoft Office Add-in

    Last modified on Wed, 2 Aug 2023
    ✔️  Available on Starter, Deliver, Grow, and Scale subscriptions 1

    What
    		Create new Teamwork.com project items and update existing files directly from Microsoft Office products.
    Why
    • Maximize your productivity by working on tasks directly from Microsoft Office apps. 
    • Keep track of the time you spend working on a document directly from the actual document. 
    • Streamline processes to keep your data synchronized and eliminate time-wasting jumping between apps. 
    Who
    • Site admins and standard users
    When
    If you are working with both Teamwork.com and Microsoft Office.

    Before you start

    The Microsoft Office add-in is available for: 
    • Microsoft Office Excel
    • Microsoft Office Outlook
    • Microsoft Office PowerPoint
    • Microsoft Office Publisher
    • Microsoft Office Word 

    Requirements

    The following are all required to be able to install and use Teamwork.com's Microsoft Office add-in: 
    • Windows operating system (The add-in does not work with Microsoft Office for Mac.)
    • Windows 7 or newer
    • Microsoft Office 2013 (or newer) or Microsoft Office 365 Desktop
    • Microsoft .Net 4.6 (Don't worry, this is usually installed as part of Windows Update.)

    Install the Microsoft Office add-in

    Download and install the Microsoft Office add-in through your Teamwork.com profile. 

    💡 The add-in is also available directly from our integrations page.
     
    1. Log in to your Teamwork.com account in a web browser tab. 
    2. Click your profile icon.
    3. Click View Profile.
    4. Select the Apps tab. 
    5. Scroll to Teamwork Office Add-in.

    6. Click Windows to download the file. 
    7. Open the file. 
    8. Follow prompts to complete the installation process. You'll:
      1. Click Next to begin
      2. Choose a local location to save the file and click Next. 
      3. Click Next to install. 
     
    The Teamwork.com app is installed on all applicable Microsoft Office products and you'll see "Teamwork.com" in the Microsoft Office ribbon. You will need to log in to Teamwork.com from Microsoft Office to start using the add-in: select Teamwork from a Microsoft Office product's ribbon menu, click Open Teamwork, then log in. 



    The integration options are listed under the Teamwork.com tab in the ribbon menu.

    Log time in Teamwork.com

    Log time spent in Microsoft Office to a Teamwork.com project.

    1. Open Microsoft Office, Word, Excel, Publisher, or PowerPoint. If you haven't already installed the add-in, check out the installation section above. 
    2. Click Teamwork from the Microsoft Office ribbon menu. 
    3. Select Log Time. 
    4. Choose a project from the project dropdown menu. Don't worry, you'll pick a task in a moment.
      1. Need to log time to a new project? Click New Project to the project field's top right and create a project to log time to. 
    5. Select a date. By default, the current date is populated.
    6. Enter a start time. 
    7. Enter the number of hours and minutes you worked and need to log towards the project. 
      1.  Was the time spent billable? Check the Billable box to mark the time as such in Teamwork.com. 
    8. Next: 
      1. Stop there: Click Log Time. You've done everything you need to do. 
      2. Level up: 
        1. Task - select a task list and task within the project to log time to. 
        2. Description - add a description and context to your time log. 
        3. Tags - apply a tag to your time log for easy filtering later. 
     
    Time is logged to the Teamwork.com project (and task, if designated). 
     

    Log time via a timer

    Start a timer in Microsoft Office and track time as you work, then log the tracked time to a Teamwork.com project and task. 

    1. ﻿Open Microsoft Office, Word, Excel, Publisher, or PowerPoint. If you haven't already installed the add-in, check out the installation section above. 
    2. Select Teamwork from the Microsoft Office ribbon menu. 
    3. Click Start Timer. 
    4. Manage your timer as you work:
      1. Click Pause when you're temporarily finished working.
      2. Click Resume when you're ready to continue working.
    5. Click Log Time when you're finished and ready to add a time log.
      1. Alternatively click Stop to end the timer and open the Log time window.
    6. Choose a project from the project dropdown. 
      1. Need to log time to a new project? Click New Project in the Create a project field's top right to create a project to log time to. 
    7. Verify that the date and number of hours/minutes logged are correct. 
    8. Enter a start time if it's needed. 
    9. Was the time spent billable? Check the Billable checkbox to mark the time as such in Teamwork.com. 
    10. Next: 
      1. Stop there: Click Log Time. You've done everything you need to do. 
      2. Level up: 
        1. Task - select a task list and task within the project to log time to. 
        2. Description - add a description and context to your time log. 
        3. Tags - apply a tag to your time log for easy filtering later. 
     
    Time is logged to the Teamwork.com project (and task, if designated).

     

    Upload current file

    Upload the Microsoft Word, Excel, Publisher, or PowerPoint file you are currently working on as a new file (or new version of an existing file) to a Teamwork.com project.

    1. Open Microsoft Word, Excel, Publisher or PowerPoint. If you haven't already installed the add-in, check out the installation section above. 
    2. Open and save the file you want to upload to Teamwork.com. 
    3. Select Teamwork from the Microsoft Office ribbon menu. 
    4. Click Upload Current File. The last saved version of the file will be uploaded to Teamwork.com.  
    5. Select a project from the project dropdown. 
      1. Need to upload the file to a new project? Click New Project in the Choose project field's top right to create a project to upload the file to. 
    6. Choose your file upload preference: 
      1. Upload as a new file and fill out the file's details:
        1. Description - add a description and context to your upload. 
        2. Category - choose an existing category to apply to your file. 
        3. Notify - select Teamwork.com users to notify. 
        4. Privacy - select which Teamwork.com users can see the file. 
      2. Upload a new version of an existing file:
        1. Check the Upload new version to an existing file box. 
        2. Select the original file from the dropdown menu to update.
    7. Click Upload File. 
      1. Not ready to upload the file just yet? Click Cancel to return to the file. Remember to save any new changes before uploading. 

    The file is uploaded to the selected Teamwork.com project.

    💡 Did you know?  You can use the Upload current document checkbox when creating projects via the add-in to upload the file to the project. This option can also be used when creating tasks or messages to include the document as an attachment.


    Best practices


    • Efficiency: Save time switching between apps by working with Teamwork.com directly from Microsoft Office products. 
    • Keep up-to-date: Having the ability to quickly and easily upload new file versions allows you to present your most recent and relevant work to your team in Teamwork.com.
