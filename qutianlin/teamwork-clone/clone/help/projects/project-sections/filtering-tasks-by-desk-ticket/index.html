    Filtering Tasks by Desk Ticket

    Last modified on Tue, 1 Aug 2023
    Within Teamwork.com, you can filter the tasks on your project to only show tasks associated with a Teamwork Desk ticket.

    Select the filters button to the top right of one of the task-related areas of your site to open the filters pane.



    You will see the Desk ticket option near the bottom of the filters pane in the following areas:

    • Everything > Active Tasks
    • Everything > Completed Tasks
    • Project > List and Board view
    • User Profile > Tasks
    • User Profile > Completed

    When Only tasks with Desk tickets is selected, only tasks that are currently associated with a ticket from Desk will be displayed.




    Note: In a project's tasks List view, attached milestones will not be displayed under their associated task list when a filter is applied.

    For more information, see: Filtering - An Overview
