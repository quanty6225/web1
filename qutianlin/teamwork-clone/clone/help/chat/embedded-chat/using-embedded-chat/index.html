    Embedded Chat

    Last modified on Thu, 23 Nov 2023
    Within Teamwork Chat, you can enable Embedded Chat for the Teamwork.com suite.

    This integration gives you direct access to Chat from within other Teamwork.com products, allowing you to engage with coworkers without having to navigate away from your work.



    Once enabled, the Embedded Chat feature is accessible to you from your other Teamwork.com accounts:

    • Teamwork.com
    • Teamwork Desk
    • Teamwork Spaces
    For more information, see: Enabling Embedded Chat
