How to find a YouTube Channel ID

Background:


Applets that use the New video by channel trigger from the YouTube service require you to enter the Channel ID of the YouTube channel you want to monitor.

The Channel ID is an alphanumeric string that uniquely identifies a channel and is different from the channel name or custom URL. Once enabled the Trigger will activate whenever the channel being monitored publishes a new video.

This guide will outline how to find the Channel ID so you can enter it in the Which channel? field when setting up your Applet.

How to find a channel's ID

To find a channel's ID, you can follow these steps:

  • First, navigate to the channel on YouTube

  • Click more at the end of the channel description to view more details

  • Scroll to the bottom and and click share channel, then select Copy Channel ID from the down down menu
     

  • Paste the Channel ID into the Which Channel field of your Applet's Trigger then press Create Trigger
