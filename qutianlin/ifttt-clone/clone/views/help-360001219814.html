Enabling and disabling Applet run notifications

You can enable notifications for your Applets to stay informed when they run or when an error prevents them from running. These notifications are sent as push notifications from the IFTTT app, so the IFTTT app must be installed on your mobile device.

There are two steps to enable Applet notifications:

  1. Grant the notifications  permission for the IFTTT app on your device.
  2. Enable notifications on the Applet you want to receive updates for.

Enable notifications for the IFTTT app

Be sure to enable the Notifications permission for the IFTTT app on your device.

iOS

  1. Open Settings.
  2. Scroll down and tap Apps.
  3. Search for and select IFTTT.
  4. Tap Notifications.
  5. Enable Allow Notifications.

Android

  1. Open Settings.
  2. Tap Apps (on some phones it's called "Apps & notifications" or "Applications")
  3. Search for and select IFTTT.
  4. Tap Notifications.
  5. Enable the "Allow notifications" (or "Show notifications") toggle

Enable notifications for an Applet

Once notifications are enabled for the IFTTT app, you can choose which Applet notifications you'd like to receive.

On ifttt.com

  1. Open the Applet you want to manage.
  2. Scroll down to the Manage Applet section.
  3. You'll see the following notification options:
    • Notify me when this runs: Sends a push notification when the Applet runs. This option isn't available if your Applet already includes a Notifications, SMS, Email, or similar notification Action.
    • Notify me if this fails to run: Sends a push notification when an error occurs and the Applet does not run.
  4. Turn on the notification options you want to use.

On the IFTTT mobile app

  1. Open the Applet you want to manage.
  2. Scroll down to the Applet's ID.
  3. You'll see the following notification options:
    • Notify me when this runs: Sends a push notification when the Applet runs. This option isn't available if your Applet already includes a Notifications, SMS, Email, or similar notification Action.
    • Notify me if this fails to run: Sends a push notification when an error occurs and the Applet does not run.
  4. Turn on the notification options you want to use.
