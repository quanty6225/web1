How to Monitor Social Media For Leads

Background

One simple way to utilise IFTTT for your business is to monitor social media sites like Twitter, Reddit or Mastodon for leads.

Enable Applets

The following three Applets work by checking each social media site for a particular search Query, and then emailing you when there is a match. Have a look by clicking any of the icons below:



   

Let's say I'm a plumber and I want to look for potential clients in Chicago via Twitter. First, I'll connect the Applet, and ensure I'm using the right Twitter account.

In the above field, I'll replace YOUR_JOB with "Plumber" and YOUR_LOCATION with "Chicago"

 

You can also change or add to this search to use terms more aligned with your customer-base or occupation. Ensure to check each social media service's search operators when creating a search, so that your search query is valid. 

Finally, you can update the subject of the email you will receive from this Applet.

You can select Add ingredient to use an ingredient from the Trigger, like the creation date of the post, or the potential client's username

Hit Save and now your Applet will be up and running.

Create your own Applets

If you want to use a different action, you can create a DIY version of the Applets above.

  • For Twitter, use the new tweet from search Trigger
  • For Reddit, use the new post from search Trigger
  • For Mastodon, use the new status from search Trigger

Combine one of these Triggers with your desired Action/s, like receiving a notification, or adding their details to a Google Sheet.
