Use Siri to Run IFTTT Applets

Siri is the voice-activated assistant from Apple. Siri can be used on your iOS or iPadOS device, HomePod, or Apple Watch to kick off an Apple Shortcut that triggers an IFTTT Applet.

Create your Applet

You can create your Applet using IFTTT Chat or the classic composer.

Use IFTTT Chat

Describe what you want your Applet to do in a prompt, including that you want to trigger it with Siri. IFTTT Chat can create the Applet using the iOS Shortcuts - Shortcut automation started Trigger.

For example:

When I trigger my IFTTT Shortcut with Siri, send me a notification.

[GIF showing how to create the Applet with IFTTT Chat]

Use the classic composer

  1. Open the IFTTT app and tap Create, then tap classic composer.
  2. Tap If This and select the iOS Shortcuts - Shortcut automation started Trigger.
  3. Tap Then That and select your Action.
  4. Tap Continue.
  5. Edit the Applet title if you'd like, then tap Finish.

Create the Siri Shortcut

  1. Open the Shortcuts app and tap the plus button ( + ) in the top right corner
  2. Tap Add Action > Apps > IFTTT > Trigger Applet
  3. Tap the blue arrow ( > ) next to 'Select an Applet', then tap Choose
  4. Select the Applet you'd like this Shortcut to run (please note that only Applets that use the iOS Shortcuts - Shortcut automation started trigger will appear in this list)
  5. Name your Shortcut by tapping Trigger Applet at the top of the screen. This will be the custom phrase you will use to trigger your Applet

Tell Siri

To run your new Applet, say ‘Hey Siri’ + the name of your Shortcut.

It’ll work on any Siri-enabled Apple device logged into the same Apple ID you used when you created your shortcut.
