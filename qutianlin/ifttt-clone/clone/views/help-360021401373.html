Creating your own Applet

How to find an Applet

With IFTTT you can connect over 1000 digital tools together to create automations and there are millions of Applets on IFTTT. There might already be an Applet that fits your needs, click here to search 🔎  for an existing Applet. 

How to create an Applet

Haven't found the right Applet? Create your own at ifttt.com/create. You can either:

  • Use IFTTT Chat: Describe the automation you want to create using natural language, and IFTTT Chat can build the Applet for you. Simply enter a prompt outing what you'd like your automation to do, then press Start bulding:
  • Use the classic editor: Select the Classic tab to use the visual Applet editor and build your automation step by step.
  1. Select the Classic tab.
  2. Click Add to the right of If This, then select the service and Trigger you want to use.
  3. Click Add to the right of Then That, then select the service and Action you want to run.
  4. Configure any available fields for your Action
  5. Click Continue to name your Applet
  6. Lastly, press finish to turn your automation on
  • IFTTT Pro users can create faster and more powerful Applets with multiple Actions. To add additional Actions, simply click the + button after adding your first Action. 
  • IFTTT Pro+ users can create even more powerful Applets with Queries, filter code, and multiple Actions. IFTTT Pro+ users can connect multiple accounts for the same service and use different accounts with different criteria or Actions in an Applet.

How to publish and share an Applet you created

Publishing your created Applets allows you to easily share them with your friends, family, followers, and more. It also makes them available for anyone else to discover and use. Check out our publishing guide to get started.

Why are some services grayed out when I'm adding a Trigger, Query, or Action?

Not every service supports every part of an Applet. Some services only have Triggers, some only have Actions, and some have Queries too. For example, the Google Assistant service only supports Triggers.

When you choose a service for a Trigger, Query, or Action, any service that can't be used for that step is grayed out under a separate heading, like "Services with no available actions."

Why can't I make an Applet with a certain Trigger/Action combination?

We aim for full interoperability between services but not all Actions and Triggers can be designed to work together. There may be technical limitations based on the service, or the combination is something the service does not allow IFTTT to do.

For example, Twitter restricts the ways new tweets can be posted using IFTTT, and does not allow Applets to be created using the New tweet from a specific user Trigger and the Post a tweet Action.
