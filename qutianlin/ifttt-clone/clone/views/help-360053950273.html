Can I add/edit filter code in the IFTTT mobile apps?

Yes! Filter code can be added to a new Applet or edited in an existing Applet directly through the IFTTT mobile app. You can add filter code using IFTTT Chat or the classic composer.

Add filter code with IFTTT Chat

With IFTTT Chat, you can describe the logic you want to add to your Applet, and it can generate and automatically add the filter code for you when making your Applet.

For example, you could ask:

When my camera detects motion, send me a notification, but only if it's after 9 PM.

IFTTT Chat can create the Applet and add filter code that checks the current time before running the notification Action.

You can also ask IFTTT Chat to add filter code to an existing Applet. Describe the logic you want to add and include the Applet ID or name of the Applet you'd like to modify.

Add filter code with the classic composer

Add filter code to a new Applet

  1. Tap Create in the center of the bottom navigation menu, then tap Classic to switch to the classic composer.
  2. Tap Add to the right of If This to add a Trigger.
  3. Tap Add to the right of Then That to add an Action.
  4. Tap the plus sign (+) between the Trigger and Action. You can optionally add a Query, then tap the plus sign to the right of Filter Code.
  5. Tap the gear icon in the top right, then tap Add filter code.
  6. Enter your filter code.

When you're finished, tap Save, then tap Continue and Finish to save your Applet.

Edit filter code in an existing Applet

  1. Tap My Applets in the bottom left of your screen.
  2. Tap the Applet you want to edit.
  3. Tap the gear icon in the top right.
  4. Tap Filter Code, then select Edit filter code from the menu that appears.
  5. Make your changes, then tap Save.

When you're finished, tap Continue and Finish to save your Applet.

Available filter code methods

When writing filter code yourself, you can view the available methods and data for your Applet's Trigger, Queries, and Actions from the filter code editor.

To view them, tap the filter icon in the top right of the filter code editor. The available methods and data are displayed by category. Tap a method or data field to expand it and view more details.

These available methods are specific to the services and Applet you're working with, so check the filter code editor for the methods available to your Applet.
