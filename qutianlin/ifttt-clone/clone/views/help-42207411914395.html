How to find your API Token

Background

Most services on IFTTT use OAuth2 to authenticate your connection. This process typically involves selecting Connect, then following the prompts to sign in with your username and password for that service.

Some services instead use an API Token for authentication. In those cases, after selecting Connect you’ll be asked to enter your API Token to finish connecting. Whether a service uses OAuth2, an API Token, or doesn’t require authentication at all depends on how the service was built.

Because each service handles Tokens differently, the steps to locate your API Token can vary. See below for instructions on how to find it for specific services on IFTTT.

Please note, the IFTTT Webhooks service generates a webhooks key upon connecting. Details on how to find your Webhooks key can be found on the Webhooks service FAQ page here.

 

Bulk Publish

  1. Log in to app.bulkpublish.com
  2. Click Developer in the left sidebar, then API
  3. Click Generate New Key, give it a name, and choose an expiration
  4. Copy the key (it starts with bp_) — it’s only shown once

Buy Me a Coffee

  • Log in to your Buy Me a Coffee account
  • Select your profile icon in the top right, then press My account
  • Select integrations from the navigation menu on the left side of the screen

  • Press Connect on the listing for IFTTT

  • Your unique API Token will be displayed below the IFTTT Token heading

  • Press copy to copy your token, then click Go to IFTTT to go to the Buy Me a Coffee service page
  • Click Connect then enter your token in the API token field
  • Press Connect to complete the connection

Buzzsprout

  • Log in to your Buzzsprout account
  • Head to https://www.buzzsprout.com/my/profile/api 
    • Or navigate there via Settings > My Profile > API Key

  • Your API key is highlighted on the page.

Claude

  • Head to https://console.anthropic.com/dashboard and login to your Claude account

  • Click Get API Key

  • Copy your key then go to https://ifttt.com/claude 
  • Click Connect Claude then enter your token in the API token field
  • Press Connect to complete the connection

Picsart

  • Navigate to the Picsart Console https://console.picsart.io/dashboard/ 

  • On the left side navigation menu, click My Apps

  • Click create app in the top right
    • Give your app a name, such as IFTTT and a description

  • Click save in the top right

  • Your Key will be displayed under the API Keys heading in the Key field 
  • Copy this key
  • Next, go to https://ifttt.com/picsart 
  • Click Connect Picsart then enter your token in the API token field
  • Press Connect to complete the connection

Skooteco

SkootEco provides a guide available here on how to generate an API Token. Follow that link, select the Guide heading, then select the SkootEco API Token Management dropdown for more details.

  • After generating your key go to https://ifttt.com/skooteco 
  • Press Connect SkootEco
  • Enter your token in the API token field
  • Press Connect to complete the connection

Transistor

  • Sign into your Transistor account
  • Click your profile icon on the top right, then select Your Account from the dropdown menu
  • Scroll down to the API Access section, then copy your key from the Your API Key field
  • Next, head to https://ifttt.com/transistor 
  • Press Connect Transistor
  • Enter your token in the API token field
  • Press Connect to complete the connection
