Help! I can't access my IFTTT account

The first thing you should do is reset your password. We'll send a reset link to the email address associated with your IFTTT account.

If you're unsure which email address you used to create your account and you're an Apple user, it's possible you signed up using Apple’s Hide My Email feature. To check for this, follow the steps outlined in this guide.

It's asking me for a six-digit two-step verification code 

Enter the two-step authentication code from the authentication method you set up when you enabled two-step authentication on your account. If you don't have access to that method, enter the backup code you saved when you enabled two-step authentication.

I'm not getting a two-step code or my backup code isn't working

There could be a few reasons for this:

  • Your SMS-based two-step verification number changed. Note: SMS is no longer supported for new two-step setups; if this applies to you, you'll need to [disable and re-enable two-step verification] using an authenticator app instead of updating the number directly
  • You switched phones and no longer have the authentication app installed
  • The backup code may have a typo, or the one you saved is outdated. Backup codes reset each time you disable and re-enable two-step verification.

Can you reset my phone number or authentication method

To maintain the security of your account, IFTTT can't update the phone number or your authentication method. We also don't have access to your backup codes.

What are my options?

If you're still stuck, the only option is to delete your IFTTT account so you can recreate it with the same email address. Please contact us with this request and we'll take care of it for you.

This will delete all current connections on your account. This cannot be reversed.
