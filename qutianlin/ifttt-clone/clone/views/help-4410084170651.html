How to create multi-action Applets

Applets are combinations of Triggers and Actions that create unique automations that would not be possible without IFTTT. Multi-action Applets allow you to run several Actions with the same Trigger event, instead of needing separate Applets all using the same Trigger.

You can create a multi-action Applet using IFTTT Chat or the classic composer.

Use IFTTT Chat

Start by heading to ifttt.com/create Describe the automation you want to create in your prompt, including the multiple Actions you'd like the Applet to run. For example:

When I post a photo to Instagram, post it my Facebook Page and Twitter as well

Use the classic composer

  1. Head to ifttt.com/create, then switch to the Classic tab
  2. Click If This and select your service and Trigger
  3. Click Then That and select your service and first action
  4. Now click the second plus button ( + ) to add additional actions

You can also add a custom delay before the actions.
