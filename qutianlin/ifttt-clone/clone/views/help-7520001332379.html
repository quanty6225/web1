How to connect Apple Shortcuts with IFTTT

Apple Shortcuts are a great way to enhance how your Apple devices integrate with the world around you. By utilizing both Shortcuts and IFTTT, you can easily connect and manage automations that simplify your life, boost your productivity, and save you time every day.


What is IFTTT?

Trusted by over 30 million users worldwide, IFTTT (If This, Then That) is a no-code automation platform that connects apps, devices, and services. It works through Applets—customizable automations that link Triggers ("if this") to Actions ("then that")—enabling seamless automation across various platforms. With a vast range of supported services, IFTTT allows users to create personalized automations tailored to their needs.

Get started with IFTTT today and unlock a smarter, more connected digital experience with one of the most versatile automation tools available.

What are Shortcuts?

The Shortcuts App is Apple's native automation program. It allows users to set specific rules for automated sequences, similar to the way IFTTT Applets operate. Additionally, the Shortcuts app provides access to services that don't natively integrate with IFTTT, such as Siri. By combining Shortcuts and IFTTT, users can extend their automation capabilities, linking the Apple ecosystem with a multitude of third-party devices and platforms.

How to Connect IFTTT to Shortcuts

Create your Applet

You can create your Applet using IFTTT Chat or the classic composer.

Use IFTTT Chat

Describe what you want your Applet to do in a prompt, including that you want to trigger it with Siri. IFTTT Chat can create the Applet using the iOS Shortcuts - Shortcut automation started Trigger.

For example:

When I trigger my IFTTT Shortcut with Siri, send me a notification.

[GIF showing how to create the Applet with IFTTT Chat]

Use the classic composer

  1. Open the IFTTT app and tap Create, then tap classic composer.
  2. Tap If This and select the iOS Shortcuts - Shortcut automation started Trigger.
  3. Tap Then That and select your Action.
  4. Tap Continue.
  5. Edit the Applet title if you'd like, then tap Finish.

 

Create the iOS Shortcut

  1. Open the Shortcuts app and tap the plus button ( + ) in the top right corner
  2. Tap Add action > Apps > IFTTT > Trigger Applet
  3. Tap the blue arrow ( > ) next to 'Select an Applet', then tap Choose
  4. Select the Applet you'd like this Shortcut to run (please note that only Applets that use the iOS Shortcuts - Shortcut automation started trigger will appear in this list)
  5. Name your Shortcut by tapping Trigger Applet at the top of the screen. This will be the custom phrase you will use to trigger your Applet

 

Trigger an Applet from a Shortcuts automation

The Automation tab within the Shortcuts app goes beyond Siri and allows you to connect your Applets to many unique functions from your Apple device.

  1. Open the Shortcuts app and tap Automation
  2. Tap Create Personal Automation
  3. Select the trigger of your choice
  4. In the Actions section, tap Add Action > Apps > IFTTT > Trigger Applet
  5. Select the Applet you'd like this Automation to run (please note that only Applets that use the iOS Shortcuts - Shortcut automation started trigger will appear in this list)
  6. Tap Next
  7. If available, toggle Ask Before Running off so you do not need to verify each time the Automation runs
  8. Feel free to change the name of your Automation, then tap Done
