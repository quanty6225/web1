Filter code generators

Filter code is a powerful feature that enables IFTTT Pro+ users to customize their Applets with expanded functionality.

Filter code can now be generated and added directly from the Applet composer when creating an Applet via ifttt.com (please note, the filter code generator is not currently available in the IFTTT mobile app). 

To use the filter code generators, follow these steps:

  • Go to ifttt.com/create from a web-browser
  • Add a trigger and at least one action to your Applet
  • Click the + sign between your trigger and action:

  • Then click the + sign to the right of Filter code:

  • Once in the filter code editor you can choose one of the three options in the Code generators section:

 

  • On the following prompt, configure the fields based on how you'd like your filter code to run, then click copy to clipboard:

 

  • Lastly, paste the code into the filter code editor, then click add filter in the top right:
  • Follow the remaining prompts to save your Applet

If you need help creating filter code for a use case that isn't covered by the Code generators, you can open a ticket with our friendly support team who will be happy to assist with creating your code.
