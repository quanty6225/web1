Troubleshooting Discord Servers Not Populating When Creating an Applet

Background:

When setting up an Applet with a Discord trigger or action, you’ll see a field to select the server and channel you want to use:

If your server or channel isn’t showing up as an option in those fields, this guide will help you resolve the issue.

Ensure the server has been added to the IFTTT Discord Service

When first connecting the Discord service on IFTTT, you’ll be prompted to select a server to add the IFTTT bot to. After adding the bot, that server will appear as an option in the which channel dropdown when creating an Applet. If one server appears but another doesn’t, it’s often because the IFTTT bot hasn’t been added to the missing server.

If a server is missing from the list, start by following these steps:

  • Go to ifttt.com/discord/settings 
  • Click Reconnect in the bottom right


  • On the following screen, ensure that the server that wasn't populating is selected in the Add to server field seen below:

  • Once selected, press continue 
  • Ensure all permissions are enabled on the follow screen then press Authorize

  • Lastly, go to ifttt.com/create. You’ll now see your newly added server listed as an option when creating an Applet, along with any servers you’ve previously added

Additional Troubleshooting: Servers not populating when reconnecting

If you’ve followed the steps in the previous section and your server doesn’t appear as an option in the Add to server field on this screen:

It’s likely because the account connected to the IFTTT Discord service doesn’t have the Manage Server permission for the server you’re trying to connect.

That permission will need to be granted to your Discord account by an admin of the server. They can do so by following these steps:

  • Right click on the Server icon, hover over Server Settings, then click Roles
  • Select the role assigned to your Discord account, go to the Permissions tab, and enable the Manage Server permission.
  • Alternatively, create a custom role for your Discord account that includes the Manage Server permission.

  • Once that permission has been added to your Discord account, follow the steps in the previous section to connect that server to the IFTTT Discord service

Additional Troubleshooting: Applet runs errors

Once your Applets are enabled, if you experience run errors, check out our guide here on granting the necessary permissions to allow IFTTT to view server messages and post to your server.
