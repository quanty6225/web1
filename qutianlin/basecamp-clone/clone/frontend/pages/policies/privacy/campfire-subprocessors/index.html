Campfire Subprocessors

Last updated: September 16, 2026 · Subscribe to changes

We use third party subprocessors, such as cloud computing providers and customer support software, to run Campfire. We establish GDPR-compliant data processing agreements with each subprocessor, extending GDPR safeguards everywhere personal data is processed.

The following is a list of personal data subprocessors we use. The country shown for each one is where the company we contract with is located:

  • Anthropic: AI assistant tools used by our staff (United States)
  • Birdie: Support request screen recordings (France)
  • Braintree: Payment processing services (United States)
  • Cloudflare: Cloud services provider (United States)
  • hCaptcha: Anti-bot protection (United States)
  • Help Scout: Help desk software (United States)
  • OpenAI: AI assistant tools used by our staff (United States)
  • Sentry: Error reporting software (United States)
  • TaxJar: Sales tax calculation (United States)
  • Twilio: Text messaging service (United States)
