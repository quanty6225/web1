# 当前桌面版本范围与限制

以用户最新要求为准：优先两个站点的桌面首页、二级页面和基本本地功能，集中检查；排除 AI、高级、付费、联机协作、移动端与外部服务。不打包，以工作目录为准。

- 保留公开首页、登录后首页、照片、Drive、联系人、日历、备忘录、提醒事项、三个 iWork 应用的已观察页面、查找设备、账户、设置、恢复和 797 个已采集的公开页面。
- 注册、验证、找回、资料及身份变更使用独立本地账户和 Mailpit SMTP；不使用源站 Cookie，不发送真实短信。
- 查找设备的播放声音、丢失模式、抹除和移除属于明确标注的本地模拟，按账户保存状态，不能控制真实设备。设备地图保留脱敏后的本地底图。
- Pages、Numbers、Keynote 现支持基础新建和编辑、自动保存、刷新重开、改名、移动、删除及恢复。Pages 提供文字字体/字号/颜色/对齐、列表、表格、图片及查找替换；Numbers 提供多工作表、行列增删、排序筛选、批量粘贴、CSV 导入、单元格格式、基础柱状/折线图、算术及 SUM/AVERAGE/MIN/MAX/COUNT；Keynote 提供幻灯片编辑、图片、背景、三种布局、淡入/滑动转场、复制、排序、演讲者备注和键盘播放。三个编辑器支持打印、复制、本地 JSON 备份导入导出及最近 20 次保存的版本恢复。行为依据补采的 Apple 官方 iCloud 帮助，编辑器界面为本地重建，未宣称具有源站编辑器截图取证。
- 下载格式明确为 HTML（Pages/Keynote）或当前工作表 CSV（Numbers）；上传的原生 iWork 文件保留下载，不承诺转换为可编辑内容。完整模板库、复杂排版、高级图表/动画、原生格式导出及实时协作仍未实现。Numbers 公式仅支持同一工作表引用与上述函数，CSV 保留输入文本和公式。
- 未采集的深层帮助、额外地区版本以及本次主应用入口以外的 Mail/Invites 等页面显示带目标说明的本地范围边界。其他 Apple 产品也使用边界页。已采集页面保留本地导航、目录、搜索和反馈。
- 定时提醒和日历提示可实际触发、关闭及延后（用户选择 5/10/15/30/60 分钟）。日期提醒可在 Notification Settings 设置账户时区内的触发时间；默认关闭。延后状态保存在服务端，重新打开应用可继续通知。浏览器关闭期间不会发送系统推送。以上属于明确配置的本地扩展，没有声称复现未确认的源站默认值。
- 数字格式包括常规、两位小数、人民币及百分比；图表使用前两列的标签/数值（最多 50 行），不支持复杂图表。含公式的表格暂不提供排序；CSV 只保留数据/公式。图片仅接受 PNG/JPEG/WebP，每张不超过约 900 KB，文档正文约 2 MB 上限。
- 个人姓名、账号、联系方式、敏感照片区域和机器可读凭据已脱敏；视频音轨已移除。这些是获授权的隐私差异。

本版的功能、浏览器、离线与独立启动检查不等于原始 BALANCED 全量 G0–G3 验收通过。更深层范围、完全一致的视觉细节和完整源站控件分母没有在本轮重新逐项闭合。

- 本轮补齐注册/找回的导航、页脚与本地地区选择；地区选择保留英文界面，仅预选注册国家及返回页面地区标签，不声称实现所有地区语言版本。共享预检的 3 个隐藏/空元素差异保留说明，未修改源证据或阈值。
